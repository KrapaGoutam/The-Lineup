## The local-tooling / real-data line, stated once

Every row above that this session or a prior one marked "approved for local tooling" means: the
**code exists, is reviewed, and is proven against disposable fixtures only**. None of it is
authorization to run against Hosted DEV, Production, or any real organization's data. The new
executor (migration `20261113120000`, functions `migration_compat_execute_role_backfill` /
`migration_compat_execute_module_config`) was built and tested entirely against a disposable local
Postgres created by `supabase db reset`; it was never pointed at Hosted DEV's URL, and its own JS
wrapper (`executor.mjs`) refuses any non-loopback URL before making a network call.
