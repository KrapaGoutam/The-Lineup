## 3. Accepted residuals (P2, documented, not changed here)

1. Navigation / module gating still keys off the org-role label (`isManager`, shared with Team/Tips/Allocation). A user who is Staff at the **active** location but manager elsewhere still sees the Bar Inventory tab; the database refuses and the module shows an empty shell, with nothing from either location rendered (asserted in the browser spec). Follow-up: gate on `activeContext.tasksDesignation` (effective tier), as Tasks/Schedule already do.
2. `inventory_live_session` tolerates a JWT without a `session_id` claim (same as merged Schedule/Payroll; Tasks/Tips are strict). GoTrue always mints `session_id`; only a self-signed token reaches that branch.
3. Shared-catalog writes require an authorized location (any location manager/assistant there). Owner decision pending on whether catalog mutation should need org-level authority.
4. Deployment narrowing (intended, consistent with Tasks/Tips/Schedule/Payroll): an org-role Shift Manager in a multi-location organization with no location assignment loses Bar Inventory access. Hosted DEV impact measured read-only: 14 multi-location orgs, 1 active shift manager (the 1 affected account), 45 owners/GMs unchanged. Take the same read-only count on PROD before the PROD release.

### What 0070 and the new tests prove

- Effective role is evaluated at the **target location**: Manager A / Staff B is authorized at A and denied at B; Location Manager B has nothing at A; Overall Owner/Assistant (no membership row) and org Owner/GM work org-wide; an unassigned multi-location Shift Manager is denied while a single-location one keeps the fallback.
- Revoked org membership, inactive location membership, banned user, a JWT whose session row is gone, an archived location, forged org+location pairs, anon and a foreign organization are all refused (database level, no app involvement).
- Decimal isolation: the same Tito's product holds exactly 12.50 at A and 4.75 at B; ledger rows carry the real caller and the correct location; previous/new values match live stock; every location-bearing RPC family (adjust, levels, bulk count, import stage, order draft, saved view, date lot, catalog write, bootstrap) refuses B for a caller who is only Staff there, and B is unchanged afterwards.
- ACTIVE module enforcement (isolated in the test transaction): a disabled location refuses an otherwise authorized manager and hides its stock; an enabled location succeeds.
- Browser: seeded shared product shows A's 12.5 to Manager A and never B's 4.75; Manager B sees 4.75 and never 12.5; Manager A switched to B (Staff) gets no data; staff read recipes but cannot edit; a foreign-organization user sees none of it.
