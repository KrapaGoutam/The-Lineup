# Feature V2-005.005: Payroll Test Matrix

## 1. Test Levels & Coverage

| Test ID   | Test Category            | Target Component                    | Description                                                              | Expected Outcome                                                                              |
| --------- | ------------------------ | ----------------------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| TC-PAY-01 | Security / Auth          | `getPayrollAccessAction`            | Manager with verified active context requests access                     | Returns `{ scope: "all", canManage: true, ... }`                                              |
| TC-PAY-02 | Security / Auth          | `getPayrollAccessAction`            | Staff user with linked attendance identity requests access               | Returns `{ scope: "self", neonUserId, person }`                                               |
| TC-PAY-03 | Security / Auth          | `getPayrollAccessAction`            | Staff user with no attendance link requests access                       | Returns `{ scope: "unlinked" }`                                                               |
| TC-PAY-04 | Security / Location      | `getPayrollRateOptionsAction`       | Overall/Org Manager requests pay rates                                   | Returns org-wide rate settings, overrides, and all active users                               |
| TC-PAY-05 | Security / Location      | `getPayrollRateOptionsAction`       | Location Manager requests pay rates                                      | Returns org rate settings and only staff assigned to active location                          |
| TC-PAY-06 | Security / Org           | `setPayrollDefaultRateAction`       | Org General Manager sets default hourly rate                             | Succeeds, records `updated_by`                                                                |
| TC-PAY-07 | Security / Org           | `setPayrollDefaultRateAction`       | Location-only Manager attempts to set default rate                       | Rejected: only organization managers can modify org pay rates                                 |
| TC-PAY-08 | Security / Org           | `setPayrollRateOverrideAction`      | Org Manager sets rate override for employee                              | Succeeds, stored in `payroll_rates`                                                           |
| TC-PAY-09 | Security / Org           | `setPayrollRateOverrideAction`      | Location-only Manager attempts to set override                           | Rejected: rate overrides are org-scoped                                                       |
| TC-PAY-10 | Security / Org           | `deletePayrollRateOverrideAction`   | Org Manager deletes rate override                                        | Succeeds, subsequent generation falls back to default rate                                    |
| TC-PAY-11 | Generation               | `generatePayrollPeriodAction`       | Location Manager generates period for assigned employee                  | Period created with `location_id = activeLocationId`                                          |
| TC-PAY-12 | Generation / Risk        | `generatePayrollPeriodAction`       | Location Manager attempts to generate for multi-location employee        | Fails closed with descriptive error requiring org manager                                     |
| TC-PAY-13 | Financial / Integrity    | `generatePayrollPeriodAction`       | Attempt to generate duplicate period for same person/month               | Fails: unique constraint violation blocked, instructs to Regenerate                           |
| TC-PAY-14 | Generation               | `generatePayrollForEmployeesAction` | Location Manager bulk-generates for branch employees                     | Successfully generates single-location staff, skips multi-location staff with explicit reason |
| TC-PAY-15 | Financial / Lock         | `regeneratePayrollPeriodAction`     | Manager regenerates unpaid, unlocked period after hours update           | Snapshot updated with fresh hours, gross recomputed, audit recorded                           |
| TC-PAY-16 | Financial / Lock         | `regeneratePayrollPeriodAction`     | Manager attempts to regenerate period with draft or confirmed payment    | Rejected by action guard and DB trigger `forbid_payroll_period_snapshot_edit`                 |
| TC-PAY-17 | Financial / Lock         | `lockPayrollPeriodAction`           | Manager locks period                                                     | Status updated to `'locked'`, future regeneration permanently blocked                         |
| TC-PAY-18 | Financial / Lock         | `unlockPayrollPeriodAction`         | Manager unlocks locked period with reason                                | Status reverted to `'draft'`, audit event recorded with reason                                |
| TC-PAY-19 | Financial / Lock         | `unlockPayrollPeriodAction`         | Manager attempts to unlock with missing/short reason                     | Rejected: reason minimum 3 characters required                                                |
| TC-PAY-20 | Payments                 | `recordPaymentAction`               | Manager records draft payment against location period                    | Draft payment created with `status = 'draft'`, balance unchanged                              |
| TC-PAY-21 | Security / Cross-loc     | `recordPaymentAction`               | Manager at Location A attempts to pay period at Location B               | Rejected: period does not belong to caller's authorized scope                                 |
| TC-PAY-22 | Payments                 | `confirmPaymentAction`              | Manager confirms draft payment                                           | Status updated to `'confirmed'`, balance immediately decremented                              |
| TC-PAY-23 | Financial / Immutability | `editDraftPaymentAction`            | Attempt to edit amount or date on confirmed payment                      | Blocked by database trigger `forbid_confirmed_payment_edit`                                   |
| TC-PAY-24 | Financial / Immutability | `deleteDraftPaymentAction`          | Attempt to delete confirmed payment                                      | Blocked by database trigger `forbid_confirmed_payment_delete`                                 |
| TC-PAY-25 | Payments / RPC           | `unconfirmPaymentAction`            | Manager unconfirms payment via RPC with reason                           | Status reverted to draft, confirmed_at/by cleared, audit event logged                         |
| TC-PAY-26 | Adjustments              | `recordAdjustmentAction`            | Manager records signed adjustment with reason                            | Adjustment inserted, balance adjusted by delta, append-only enforced                          |
| TC-PAY-27 | Adjustments              | `recordAdjustmentAction`            | Attempt to record zero delta adjustment                                  | Rejected by input validation and DB check constraint                                          |
| TC-PAY-28 | Dashboard / Location     | `getPayrollDashboardAction`         | Location Manager views dashboard                                         | Metrics and grouped periods reflect only branch-attributed periods                            |
| TC-PAY-29 | Dashboard / Org          | `getPayrollDashboardAction`         | Org Manager views dashboard                                              | Metrics reflect all organization periods                                                      |
| TC-PAY-30 | Dashboard / Staff        | `getPayrollDashboardAction`         | Regular staff views dashboard                                            | Receives only own locked/paid periods; zero org KPI liability totals                          |
| TC-PAY-31 | Statements               | `getCombinedMonthlyStatementAction` | Staff fetches own statement                                              | Returns corporate letterhead timesheet + locked payroll calculation                           |
| TC-PAY-32 | Statements               | `getCombinedMonthlyStatementAction` | Staff attempts to fetch another employee's statement                     | Rejected with authorization error                                                             |
| TC-PAY-33 | Statements               | `getCombinedMonthlyStatementAction` | Location Manager fetches statement for foreign branch employee           | Rejected with authorization error                                                             |
| TC-PAY-34 | RLS / PostgREST          | Direct SQL / PostgREST DML          | Attacker attempts direct insert/update on `payroll_periods`              | Blocked by RLS policies using `private.payroll_*` helpers                                     |
| TC-PAY-35 | RLS / Overall Actor      | Overall Admin operations            | Overall Owner/Manager without tenant membership executes payroll actions | Allowed by overall tier resolution and profiles FK without constraint error                   |
| TC-PAY-36 | Module Enforcement       | Backend Module Guard                | Payroll executed at location where payroll module is disabled            | Blocked when module enforcement is active                                                     |
| TC-PAY-37 | Context Stale            | Stale tab assertion                 | Request sent with outdated workspace expectation                         | Returns `contextStale: true` with standard reload error                                       |
