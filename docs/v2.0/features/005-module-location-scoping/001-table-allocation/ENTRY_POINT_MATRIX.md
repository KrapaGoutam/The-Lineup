## Independent closeout corrections (2026-11-06)

The table above records the original investigation, not executed acceptance. Direct INSERT/UPDATE/DELETE grants on sessions, rotation graph, claims and board_events were already revoked by 20261023110000_table_rotation_v2_trusted_mutations.sql; no new direct-write policies are introduced. Dining tables/areas retain manager FOR ALL policies, now bounded by additional restrictive location policies. The loader source is unchanged because locationForLoader already uses canonical verification, and both operational call sites pass explicit scope. The history action now explicitly checks the live session. Missing/falsey expectations on legacy undo/redo/history use the canonical server location; execute compares its synthesized expectation against that same server location. Client parameters never select it.
