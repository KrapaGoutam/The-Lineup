## Mutation checks (tests are not vacuous)

Targeted breakage of the migration, each caught by pgTAP: read policy ignoring active org membership (`MC-010e`), manage helper widened to every org role (`MC-008*`, `MC-009*`), `location_id` made mutable (`MC-011*`), audit columns client-controlled (`MC-007c`, `MC-011f`), archived guard disabled (`MC-012j–k`). TypeScript: `isModuleUsable` accepting `missing`, and a database error returned as an empty configuration — both caught by Vitest. Compile-time: an unregistered `AppTab` and an unregistered DB enum value both fail `tsc`.

## Deferred to Local (real JWT, hosted DEV)

`tests/real/module-config.db.real.test.ts` (MCR-01…10) exercises the same security properties through PostgREST with real Supabase Auth sessions and the real reader. It was typechecked and linted in Cloud and **executed on hosted DEV: 10/10** (EVIDENCE §7.6). Denied writes are additionally verified against stored state with the service role, including silent zero-row UPDATEs; teardown fails loudly on any surviving tracked fixture (EVIDENCE §7.3).
