## Hard rules

- Never generate or autofill tips. Show only non-empty `variant.tips`.
- No tip means no note element at all: no "No tip", no dash, no empty card.
- Do not add columns, tables, migrations or RLS changes for this design.
- Do not change step or ingredient wording; emphasis is styling only.
- Perfect and House keep their current semantics and selection logic (`variantHasPersistedContent`).

## Quantity splitting (presentation helper)

Input `amount`, `unit` strings.

1. If `unit` is `oz`/`ml` and `amount` parses to a number (accept `¼ ½ ¾`, `1/2`, `1 1/2`, decimals): render whole and fraction columns with two decimals in oz (`1.50`, `0.25`), at most one in ml.
2. Otherwise render the raw `amount` in the whole column and `unit` in the unit column (`8–10`, `top`, `1 dash`).
3. The `oz | ml` toggle applies rule 1 only (30 ml per oz in the mock).
4. If `amount` is empty and `unit` is text, render only the unit (`top`).
   Add unit tests; do not alter stored values.
